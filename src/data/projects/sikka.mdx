# Sikka Engineering: Corporate Website & Custom Admin Dashboard

## Overview

Sikka Engineering is a modern corporate website developed to establish the company's online presence while providing a powerful custom-built Content Management System (CMS). The project includes a responsive public-facing website and a secure MERN-based admin dashboard that allows administrators to manage all website content without writing or modifying code.

## Website Features

- Responsive corporate website optimized for desktop, tablet, and mobile devices
- Dynamic Services section
- Projects portfolio management
- Case Studies showcase
- Career & Job Posting page
- Contact & Inquiry forms
- SEO-friendly pages and optimized performance
- Modern and clean UI for better user experience

## Custom Admin Dashboard

A complete MERN-based admin panel was built to manage every dynamic section of the website.

### Dashboard Features

- Secure Admin Authentication
- Dashboard Overview with statistics
- Manage Services (Create, Edit, Delete)
- Manage Projects
- Manage Case Studies
- Manage Job Postings
- Manage Contact/Inquiries
- Manage Website Content
- Image Upload & Management
- Complete CRUD Operations
- Responsive Admin Interface

The dashboard enables non-technical users to update website content instantly without requiring developer support.

## Challenges

- Designing a scalable custom CMS instead of using third-party solutions.
- Building reusable CRUD modules for different content types.
- Managing file uploads and dynamic content efficiently.
- Keeping the admin dashboard simple while supporting multiple modules.

## Tech Stack

### Frontend

- React.js
- Tailwind CSS
- JavaScript

### Backend

- Node.js
- Express.js
- MongoDB
- JWT Authentication
- REST APIs

## Impact

- Reduced dependency on developers for website updates.
- Enabled administrators to manage all business content from a single dashboard.
- Improved content management workflow with secure authentication and role-based access.
- Delivered a scalable solution that can easily support future modules.

## Key Learnings

- Designing scalable CMS architecture
- Building reusable CRUD systems
- Authentication & Authorization using JWT
- REST API development
- File upload handling
- Production deployment and maintenance
- Developing enterprise-level admin dashboards
