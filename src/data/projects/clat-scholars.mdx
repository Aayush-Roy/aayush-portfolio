## Overview

**CLAT Scholars** is a modern educational platform focused on **CLAT and law entrance exam preparation**. The platform provides students with a centralized digital experience to explore preparation programs, educational resources, and important information related to their law entrance journey.

The website was built as a **full-stack MERN application**, featuring a responsive frontend, backend APIs, MongoDB integration, Cloudinary-powered media management, and production deployment on a Hostinger VPS.

## Key Features

* **CLAT Preparation Platform**: Presents CLAT-focused preparation programs and educational offerings in a structured experience.
* **Course & Program Discovery**: Allows students to explore available preparation programs and learning offerings.
* **Educational Content**: Organizes important information and resources for CLAT aspirants.
* **Dynamic Content Management**: Built dynamic sections and content powered by backend APIs.
* **Cloud Media Management**: Integrated Cloudinary for storing and managing website images and media assets.
* **Responsive UI**: Designed the platform to provide a smooth experience across desktop, tablet, and mobile devices.
* **Modern User Experience**: Implemented clean layouts, interactive sections, and engaging UI elements for students.
* **REST APIs**: Developed backend APIs using Node.js and Express.js for handling application data and functionality.
* **Database Integration**: Used MongoDB for storing and managing application data.
* **Production Deployment**: Deployed and configured the full-stack application on a Hostinger VPS.

## Tech Stack

* **MongoDB** — NoSQL database for application data
* **Express.js** — Backend framework for REST API development
* **React** — Component-based frontend architecture
* **Node.js** — Server-side runtime environment
* **Cloudinary** — Cloud-based image and media management
* **Hostinger VPS** — Production hosting and server deployment

## Impact

The platform provides **CLAT aspirants with a centralized digital experience** to explore preparation programs, educational content, and learning resources.

By combining a modern React frontend with a **MERN-based backend, Cloudinary media management, and VPS deployment**, the platform delivers a scalable and production-ready web experience for CLAT Scholars.
