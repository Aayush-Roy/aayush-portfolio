# Being AV: Full-Stack Website, Custom CMS & Inquiry CRM

## Overview

Being AV is a modern, content-driven business website developed using Next.js, TypeScript, Node.js, Express.js, MongoDB, and Cloudinary.

The project was built with a strong focus on scalability and content management. Instead of keeping website content hardcoded inside the frontend, a custom React-based admin dashboard was developed to function as both a **CMS and Inquiry CRM**.

The dashboard allows administrators to manage almost the entire website from a centralized interface, including the home page, banners, products, blogs, About Us content, pages, images, and other dynamic sections.

The system also includes an inquiry management module that allows the business to receive, view, manage, and track inquiries submitted through the website.

## Custom CMS Dashboard

A custom React-based admin dashboard was developed to give administrators complete control over the website content.

The CMS eliminates the need to modify frontend code whenever website content needs to be updated.

### Content Management

Administrators can manage various website sections directly from the dashboard.

- Manage homepage content
- Manage hero banners
- Manage products
- Manage product information
- Manage blogs
- Manage About Us content
- Manage website pages
- Manage images and media
- Create, update, and delete content
- Publish and update content dynamically
- Centralized content management

The frontend consumes this content through REST APIs and dynamically renders the latest data on the public website.

## Inquiry CRM

Alongside the CMS, the admin dashboard includes a dedicated inquiry management system.

Website visitors can submit inquiries through the public website, which are then stored in MongoDB and made available to administrators through the dashboard.

### CRM Features

- Capture website inquiries
- View inquiry details
- Manage incoming inquiries
- Centralized inquiry dashboard
- Track customer requests
- Review submitted contact information
- Manage inquiry records
- Separate inquiry management from website content management

This provides the business with a simple CRM workflow without requiring a separate third-party CRM platform.

## Dynamic Website Architecture

One of the key aspects of the project was making the public website content-driven.

Instead of hardcoding every section, the frontend retrieves dynamic data from the backend APIs.

For example, administrators can update a product or homepage banner from the dashboard, and the updated content can then be reflected on the public website without requiring changes to the frontend source code.

This approach makes the website easier to maintain and provides a scalable foundation for adding new CMS modules.

## Challenges

### Building a Custom CMS

One of the primary challenges was designing a CMS that could manage different types of website content while remaining simple for non-technical administrators.

The system was structured around reusable CRUD patterns so that different content modules could be managed through a consistent dashboard interface.

### Making the Website Fully Dynamic

The website contains multiple sections that need to be updated regularly.

Instead of hardcoding this content, API-driven dynamic rendering was implemented so that the frontend could consume and display data managed through the CMS.

### Combining CMS and CRM

The dashboard needed to serve two different purposes:

1. Managing website content.
2. Managing customer inquiries.

Both workflows were integrated into a single administrative interface while keeping their data and functionality logically separated.

### Media Management

Products, banners, blogs, and other pages require images. Cloudinary was integrated to provide reliable media storage and delivery while keeping the application server lightweight.
