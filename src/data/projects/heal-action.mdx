# Heal Action Physiotherapy

## Overview

A professional **physiotherapy website** developed for **Heal Action Physiotherapy**, designed to provide visitors with clear information about physiotherapy services while making it easy to get in touch and enquire about appointments.

The website was built using **Next.js** with a responsive and user-friendly interface, along with backend communication through **PHP Mailer** and **WhatsApp API integration** for handling enquiries and improving direct communication with potential patients.

## Key Features

### Professional Healthcare UI

Designed and developed a clean, professional interface tailored specifically for a physiotherapy and healthcare business.

- Responsive design across devices
- Service-focused sections
- Clear call-to-action elements
- Modern healthcare-oriented layout
- Reusable components
- Mobile-friendly navigation

### Appointment & Enquiry System

Implemented enquiry functionality to allow visitors to contact the clinic directly through the website.

- Appointment enquiry form
- Form data handling
- Email notifications
- User-friendly form experience
- Validation and error handling

### PHP Mailer Integration

Integrated **PHP Mailer** to handle website enquiry emails and provide reliable communication between the website and the clinic.

- SMTP-based email delivery
- Contact form email notifications
- Structured enquiry information
- Backend email processing

### WhatsApp Integration

Integrated the **WhatsApp API** to provide visitors with a direct communication channel.

- Direct WhatsApp enquiry
- Quick contact functionality
- Call-to-action integration
- Improved user-to-business communication
