# Refokus

## Overview

A frontend recreation of the **Refokus** website built with **React.js**, focusing on pixel-perfect UI implementation, smooth scrolling, and highly interactive animations.

The project was created to recreate the visual language and interactive experience of the original Refokus website while exploring modern frontend animation techniques using **GSAP, Locomotive Scroll, and Framer Motion**.

## Key Features

### Pixel-Perfect UI

Recreated the overall structure, layout, typography, spacing, and visual elements of the Refokus website with a strong focus on matching the original design.

- Modern agency-style interface
- Responsive layouts
- Interactive sections
- Smooth transitions
- Reusable React components

### Advanced Animations

Animations are a major part of the project and were implemented using multiple animation libraries.

- GSAP-powered animations
- Scroll-based interactions
- Framer Motion transitions
- Element entrance animations
- Hover and interaction effects

### Smooth Scrolling

Integrated **Locomotive Scroll** to create a smooth scrolling experience and enhance scroll-based animations throughout the website.
